# Human Submission Examples

This directory contains example JSON submission files for humans participating in the benchmark.

## Files

- `reachability_2node_example.json` - Simple 2-node reachability task
- `bgp_2as_example.json` - Two autonomous systems with eBGP
- `ospf_3node_example.json` - Three routers in OSPF area 0

## Documentation

For detailed information, see:
- [Submission Format Guide](../../docs/SUBMISSION_FORMAT.md) - Submission format specification
- [Human Benchmark Guide](../../docs/HUMAN_BENCHMARK_GUIDE.md) - Complete guide for human participants

## Usage

Copy these examples and modify them for your submissions:

```bash
cp reachability_2node_example.json my_submission.json
# Edit my_submission.json with your configuration
```
