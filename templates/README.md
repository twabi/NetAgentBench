# Benchmark JSON Templates

This directory contains template JSON files that define the input formats for the Network Configuration Benchmark system.

## Files

- `task_template.json` - Basic two-node reachability task
- `advanced_task_template.json` - Complex three-node OSPF topology
- `submission_template.json` - Basic BGP configuration submission
- `advanced_submission_template.json` - Complex OSPF configuration submission

## Documentation

For detailed format specifications, see:
- [Task Format Guide](../docs/TASK_FORMAT.md) - Task definition specification
- [Submission Format Guide](../docs/SUBMISSION_FORMAT.md) - Submission format guide

## Usage

These templates serve as starting points for creating your own tasks and submissions. Copy and modify them as needed.
